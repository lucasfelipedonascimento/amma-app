# Decisões

| Data       | Decisão                                                                                                                          | Motivo                                                                                                                                                      |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-29 | pnpm 9 + Turborepo + catálogo de versões                                                                                         | Pedido do projeto; cache e execução só do que mudou                                                                                                         |
| 2026-10-29 | Prisma 6 (com `postgresqlExtensions` p/ PostGIS)                                                                                 | Mais simples para dev solo. Consultas geoespaciais usarão SQL cru                                                                                           |
| 2026-10-29 | Versões "conservadoras": TypeScript 5.9, NestJS 11, Prisma 6, Vitest 3, ESLint 9                                                 | O npm já traz majors mais novos (TS 7, Nest 12, Prisma 7/8-rc); preferi estabilidade e compatibilidade com Node 20. Revisar depois                          |
| 2026-10-29 | Expo 58 / RN 0.88 (alinhado por `expo install --fix`)                                                                            | Versões mutuamente compatíveis ditadas pelo Expo                                                                                                            |
| 2026-10-29 | `node-linker=hoisted` no `.npmrc`                                                                                                | Compatibilidade do Metro com monorepo pnpm                                                                                                                  |
| 2026-10-29 | Postgres exposto na porta **5433** (configurável por `POSTGRES_PORT`)                                                            | A 5432 já estava ocupada na máquina de desenvolvimento                                                                                                      |
| 2026-10-29 | Testes com Vitest (shared e api)                                                                                                 | Simples e rápido; mesma ferramenta em todo o monorepo                                                                                                       |
| 2026-10-29 | CI em GitHub Actions (assumido) com filtro de `paths`; deploy é esqueleto                                                        | Destino de deploy ainda indefinido; não inventar integrações                                                                                                |
| 2026-10-29 | Dinheiro em centavos (`Cents`), datas em UTC                                                                                     | Definido no projeto                                                                                                                                         |
| 2026-10-29 | Taxas arredondadas **para baixo**; piso arredondado **para cima**                                                                | O centavo quebrado nunca prejudica o trabalhador                                                                                                            |
| 2026-10-29 | Taxa base (10%) e taxa de associação (0/2/4%) incidem ambas sobre o valor **bruto**                                              | Interpretação mais simples; confirmar se a associação deve incidir sobre o líquido                                                                          |
| 2026-10-29 | Resto de cota (< R$ 5) acumulado em `remainderCents`                                                                             | Nenhum centavo de taxa de associação se perde                                                                                                               |
| 2026-10-29 | Valores do piso por km/min são **parâmetros** (`FloorRates`), não constantes                                                     | Não foram definidos; serão configuração da associação                                                                                                       |
| 2026-10-29 | Cancelamento só até `ARRIVED`; `EXPIRED` só a partir de `REQUESTED`; entregas usam a mesma máquina de estados                    | Simplicidade; ajustar quando houver regra de cancelamento/multa                                                                                             |
| 2026-10-29 | PostGIS criado por SQL na migração `init`, sem `extensions = [postgis]` no schema                                                | A imagem Docker já traz extensões extras; o Prisma via divergência e pedia reset do schema                                                                  |
| 2026-10-29 | Lat/lng como `Float` por ora                                                                                                     | Colunas PostGIS entram junto com a busca por proximidade (etapa futura)                                                                                     |
| 2026-10-29 | Auth por e-mail + senha (bcryptjs, custo 10) e JWT de 7 dias; `JWT_SECRET` por variável de ambiente                              | Sem integração externa; login por SMS/telefone depende de provedor, fica para depois                                                                        |
| 2026-10-29 | Cadastro só permite PASSENGER, WORKER, MERCHANT; ADMIN é atribuído manualmente                                                   | Evita auto-promoção a administrador                                                                                                                         |
| 2026-10-29 | `User.roles` como lista; extrato de cotas em `QuotaEntry`                                                                        | Uma pessoa pode ter mais de um perfil; saldos são registros contábeis rastreáveis                                                                           |
| 2026-10-29 | Teste confere que o enum `RideStatus` do Prisma == `RIDE_STATUSES` do shared                                                     | Evita divergência entre banco e regras                                                                                                                      |
| 2026-10-29 | **Login por telefone com OTP substituiu e-mail/senha**                                                                           | Pedido na Etapa 2. Modo simulado (`OTP_MODE=simulated`): código no log e na resposta; recusado em produção. SMS real depende de provedor (não implementado) |
| 2026-10-29 | Papéis renomeados: PASSAGEIRO, MOTORISTA, COMERCIANTE, ADMIN                                                                     | Vocabulário do projeto; MOTORISTA cobre entregador                                                                                                          |
| 2026-10-29 | JWT de acesso de 15 min com só o `sub`; papéis lidos do banco a cada requisição                                                  | Papéis nunca ficam desatualizados e conta excluída é barrada na hora                                                                                        |
| 2026-10-29 | Refresh token opaco (30 dias), em hash, com rotação e detecção de reuso (revoga todas as sessões)                                | Limita o estrago de um token roubado                                                                                                                        |
| 2026-10-29 | OTP: 6 dígitos, validade 5 min, 5 tentativas, 3 pedidos/10 min por telefone, uso único, hash com HMAC ligado ao telefone         | Segurança básica sem serviço externo                                                                                                                        |
| 2026-10-29 | Aprovação do motorista calculada em `shared` (`driverApproval`) pelo último envio de cada tipo (CNH, documento do veículo, foto) | Regra testável e igual no app e na API                                                                                                                      |
| 2026-10-29 | Documentos em disco local (`UPLOAD_DIR`) atrás de `StorageService`; tipo validado pelos bytes                                    | Sem inventar integração; trocar por bucket privado é só implementar a mesma interface                                                                       |
| 2026-10-29 | Exclusão de conta = anonimização; financeiro mantido sem identificação                                                           | Equilibra LGPD e obrigação contábil                                                                                                                         |
| 2026-10-29 | Preço = base + km + minuto com piso, tabela **versionada** (`PricingConfig` + `selectPricingConfig`)                             | Etapa 3; valores reais continuam sendo configuração da associação                                                                                           |
| 2026-10-29 | Ledger em partidas dobradas, em memória e append-only; estorno só uma vez; cotas derivadas da conta `WORKER_QUOTAS`              | Etapa 3; persistência em tabela somente-inserção fica para quando existirem as corridas                                                                     |
| 2026-10-29 | App mobile sem biblioteca de navegação: o estado do usuário decide a tela                                                        | Menos dependências; migrar para expo-router quando houver mais telas                                                                                        |
| 2026-10-29 | `postinstall: prisma generate` na API                                                                                            | O CI roda testes antes do build e precisa do cliente gerado                                                                                                 |
